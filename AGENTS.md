# Project guidance

For game UI work, follow [Game UI principles](design/game-ui-principles.md).

Use [Mobile card-board research](design/mobile-card-board-research.md) as supporting evidence. Distinguish documented competitor behavior, screenshot observations, and Squabblemon design decisions.

Improve hierarchy, responsiveness, readability, and feedback while preserving existing gameplay rules, unlimited district card populations, character artwork, and normal detail interactions.

For architecture, feature boundaries, performance, API integrity, and release work, follow [Engineering standards](design/engineering-standards.md).
