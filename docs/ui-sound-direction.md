# Interface sound direction

## Identity

Commission a small original sound library: tactile street objects, record scratches, train hardware, coin textures, and restrained cinematic bass. Preserve the soundtrack and character specials as the main voices. These are production briefs; this UI pass does not claim to include new mastered audio.

| Moment | Sound brief | Length |
| --- | --- | --- |
| Button / tab | Soft mechanical click; three subtle variations | 60–120 ms |
| Express opens | Train-door latch followed by a short air release | 350 ms |
| Match found | Two bell notes, needle scratch, solid versus impact | 900 ms |
| Card / pack reveal | Paper and foil rip; one rarity accent | 400–900 ms |
| XP / RP count | Quiet grouped ticks, one completion stamp | 500–900 ms |
| Rank promotion | Medal ring plus a short brass flourish | 1.2 sec |
| District settles | One distinct stamp per district, then control accent | 150 ms each |
| Clout received | A small coin roll; avoid a casino jackpot sound | 450 ms |
| Reward receipt | Bag rustle, warm confirmation tone | 600 ms |
| Victory | One weighty hit into a short upward phrase | 1.4 sec |
| Defeat / retry | Low wooden knock and gentle reset sweep | 450 ms |

## Delivery and integration

- Keep 48 kHz, 24-bit WAV masters with clean tails and no clipping. Export compact Opus and AAC delivery files; audition on phone speakers, earbuds, and laptop speakers.
- Add files behind the existing feedback preferences and audio-unlock interaction. Never start audio before user interaction. Honor mute immediately.
- Limit simultaneous interface cues to two. Coalesce score ticks rather than playing one per number. Character specials take priority; duck interface sounds beneath them.
- Cancel pending cue sequences on navigation or skip. Use one cue per accepted purchase receipt so retries cannot play duplicate rewards.
- Test quiet and loud soundtrack passages; set gain by listening to the complete mix. Keep useful headroom for specials.
- Store authorship and redistribution rights with each source master.

## Fade Market handoff

The store uses existing Clout terminology. Its separately labeled demo balance and receipts are device-local and cannot grant account currency, cards, or styles. Prices and curated showcase contents are placeholders, not published random-pack odds.

Before enabling real checkout, connect server-verified receipts, stable product IDs, idempotent fulfillment, and account entitlement records. Show final price, contents or actual odds, and cosmetic-only style effects before purchase. Keep earned Clout paths available; avoid timers and manufactured scarcity.
