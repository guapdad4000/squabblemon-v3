# Player mats: character worlds

## Art direction locked October 21

Match Squabblemon's existing anime / cel-shaded arcade fighting-game art. Use the character card as the identity reference and an existing stage as the rendering reference. Bold ink contours, deliberate two- or three-tone shadows, expressive proportions, restrained color groups and selective supernatural light. Avoid overly rich saturation, rainbow gradients and glossy rendering. The user's Marvel versus Capcom reference describes energy and rendering; create original Squabblemon environments.

Every mat must answer: **Whose world is this, and what does their ability do to it?** Design the answer before prompting. A different wall color or a large pasted portrait is insufficient. Build one memorable object or place large enough to contain all three lanes. The visual should remain identifiable with the cameo hidden.

Use the existing face, hair, clothes, accessories and ability. Do not infer identity from the name. Kyle carries Smile Bombs; Captain Jigga's setting is an aircraft cabin. Read the catalog entry and inspect the actual art before each generation. Fist emblems only, including jewelry, shoes, signs and distant props. Replace legacy crown motifs when generating new art.

## Composition contract

- One source image represents **one player's half**, with three authored open areas in one continuous scene. No six-tile board, repeated arenas or miniature copies of the same room.
- Master: 1536 × 1024. Lane centers: x = 256, 768, 1280 (16⅔%, 50%, 83⅓%). Visual activity is peripheral; each center remains broad, low contrast and usable for multiple cards.
- For the initial master, keep a useful quiet band around y = 52–58%. Open areas should extend roughly y = 25–82%, with width around 22–25% of the master each. These are authoring guides, not visible card frames.
- Let the setting explain the lanes: clear soil between roots, the panels of a giant basketball, three placemats on one dinner table, columns of a giant ledger. Props can connect all three regions.
- Highest detail belongs around the outer edges and between open areas. Place the character naturally within a bottom-left or bottom-right corner of the illustration. Keep the head within the lower half so it survives the PvP split. Baked-in cameos are welcome; separate layers are an implementation option, not an art-direction requirement. Each composition shows the character once.
- Runtime anchors each source third to the corresponding real lane. Crop proportionally; never stretch. Equal upper/lower halves share the lane's center. The exact source crop changes with viewport, so do not promise every peripheral prop survives.
- The layout owns the split, lane widths, gutters, hit targets, scores and labels. Generated art does not contain HUD, card slots, numbers, UI words or fake controls.
- Review raw art, a lane-guide overlay, and populated real Battle fixtures at 320×568, 390×844, 768×1024, 844×390, 1280×800 and 1920×1080. Check crowded scrolling and both player seats too.

## Generation and acceptance

1. Read current character ability and visually inspect its art.
2. Write the single-scene metaphor, three quiet centers, two ability details and one identity detail.
3. Generate using the built-in image tool, one asset per call, with those references attached. Save the exact prompt and reference paths.
4. Inspect linework, identity, emblems, open areas and visual variety. Reject generic courts, painterly/realistic style drift, repeated panels and misplaced character traits.
5. Test with real cards and HUD. An attractive illustration can still fail as a mat. Keep failed candidates outside shipped assets.
6. Advance collection art only when the composition works. Clearly label generated pilots versus briefs; never imply that a brief is finished art.

The earlier blue six-cell court is rejected and archived outside runtime assets. Buddy, Kyle and the Hooper audition establish the corrected direction. All 18 remaining character briefs have now received reference checks, original illustration generation and clean environment edits.
