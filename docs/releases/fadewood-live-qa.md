# Fadewood live QA follow-up

Continue in the street travels to an arc host and opens a dismissible character panel. Continue from any character offering that arc opens the chapter map at the resumed chapter. Selecting a map stop is the explicit action that opens dialogue or combat briefing. Back to map preserves the chapter.

Resume hints persist per account as presentation only. Without a hint, server last-played timestamps select the most recently played arc; old unacknowledged post-dialogue does not override later progress. Explicit saved post-dialogue can still resume. Completed fights, rewards and eligibility remain server-owned.

Phones use a compact 44px minimum Continue sign below the heading, leaving the movement area visible. Chapter fetches time out after 20 seconds and expose retry; pending node overlays allow return to map.

Dr. Fade and the Kumite mode selector expose Breakthrough CPU practice at `/game/kumite/breakthrough/practice`. It grants no account rewards, retains deck legality checks and does not open online room admission. Full public entry and multiplayer remain subject to the existing release gate.
