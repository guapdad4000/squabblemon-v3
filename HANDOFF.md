Current handoff status as of September 7, 2026.

## Ready
- Three-district, six-round playable card-battle prototype
- Seven starter decks and Patch 0.2 / Patch 0.3 playtest variants
- OG Concrete and Gold Foil themes
- 20 of 36 roster characters wired to new transparent production-style art
- Animated Yellow Liquid Orb wired to Hype
- Animated Flame Orb wired to SQUABBLE

## GitHub source bundle
`handoff/SQUABBLEMON_DEV_SOURCE.zip` contains the current modular prototype source, docs, roster status, sprite map, Patch 0.3 playtest code, and art/FX handoff notes.

## Binary art package
The complete transparent art package is maintained as `SQUABBLEMON_ART_TRANSPARENT_COMPLETE.zip` in the final handoff archive. It is too large for the chat GitHub connector to push as a normal repository file, so the canonical binary master is the delivered handoff ZIP rather than this GitHub tree.
