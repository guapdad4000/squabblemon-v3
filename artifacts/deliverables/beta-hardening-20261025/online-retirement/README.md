# Rules-version retirement and replay recovery

Local source at the shared v2-performance-parity worktree, 2026-10-25. No deployment or live database operation was performed. Both ONLINE_RULES_VERSION and CARD_BALANCE_VERSION are 64 because the authoritative CPU replay policy changed.

## Behavior

- Incompatible rooms close neutrally under the room lock before CPU advancement, timeout, commands or rank settlement. Public recovery does not evaluate an old board. No winner, loss, rank delta or new reward receipt is generated by retirement.
- Affected in-progress Kumite brackets cancel before any pending result is processed. Issued sibling rooms close, completed bracket history and prior receipts remain, and no champion or bye is invented. Completed tournaments remain intact.
- Unfinished reward matches reject incompatible replay with HTTP 409 and code `rules-updated`. Completed reward receipts remain recoverable.
- Retrying POST /player/matches with the same challengeRunId clears only the stale unfinished binding under the run lock and issues one replacement under the normal issuance lock. The same encounter, seed, crew, run and daily entry remain; old match/checkpoint records are retained.
