# Method

All nine elemental recipes were screened against six opponents in set A and a different set B. Each recipe had 96 matches per set: four training tiers, both owner seats, greedy and seeded legal policies. Baseline is the retained v59 payoff patch, not a pre-buff Plant version.

Set A: seed elemental-screen-oct12-227; rotation 23; Receipts, Water, Fire, Fitness Routes, Earth Tax, Who You Know.
Set B: seed elemental-confirm-oct12-263; rotation 29; Red, Blue, Cellblock Pressure, Receipts, Tour Money, Fitness Routes.
Set C: seed payoff-holdout-20261012-191; rotation 19; Red, Blue, Electric, Who You Know, SquabbleHouse Shift, Cellblock Pressure. This is the earlier payoff holdout draw set, rerun against the current v59 baseline. It is fresh relative to A/B selection but is not an untouched preregistered final evaluation after later Dark iterations.

Recipes, tiers, seats, policies, seeds and rotations are paired. Draws count as half a win. A/B comparisons for retained Plant use candidate/confirm-candidate; retained Air uses air-payoff/confirm-air-payoff. The Dark changes present in those intermediate candidates do not occur in their opponent recipes. Final retained-holdout reruns all changed decks and shared-card controls with rejected Dark changes removed. Source snapshots, raw results, recipe plan and retained diff are provided.

Small case groups share draw orders and are not independent player samples. Treat percentages as diagnostic bot scores, not confidence-backed player win rates or a new full-field league ranking. Air's set B regression is retained in the report, not hidden by the pooled average.
