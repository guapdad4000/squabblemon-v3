# Immersive battle result artwork

Generated with imagegen using the existing win-wide, loss-wide, win-scene-wide and loss-scene-wide as scene references, and the current gold fist wordmark from the Squabblemon Brand Kit.

## Direction
Preserve Dr. Fade, his outfit, each setting and outcome emotion. Clean cel-shaded anime fighting game illustration. Replace old crown/SM emblems with raised fists. Remove baked UI, lettering and reward boxes. Wide scenes keep the character on the left and quiet space on the right; portrait scenes reserve the lower floor for live overlays. Two win scenes (celebration, gym), two loss scenes (broken throne, harbor). The portrait celebration was regenerated to fix a floating, severed torso before integration.

## Layers
- Eight scene backgrounds: two outcomes × two variants × wide/portrait.
- wordmark.webp: current supplied gold wordmark, converted from the brand kit.
- panel.webp: generated blank ivory/brass reward plaque with fist crest, no words or crowns.
- gloves.webp: generated red boxing gloves with gold fist patches, transparent foreground layer.
- Paper/confetti is rendered as lightweight CSS layers. Existing W/L animations retained.

Original generated PNG files are retained in the Codex generated_images directory for this task. WebP exports use quality 90–95.
