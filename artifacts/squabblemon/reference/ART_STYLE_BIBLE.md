# Squabblemon Character Art Style Lock

- Premium anime / fashion concept-art finish
- Full-body silhouettes on transparent background
- Crisp outer contours with selective interior linework
- Painterly shading, high material readability, restrained texture
- Slightly elongated legs with emphasized hands, footwear, and signature props
- Streetwear / luxury / occupational archetype identity before fantasy costume
- One dominant palette family plus a focused accent color
- Strong enough silhouette to read at small card size
- Props should communicate the joke / social archetype immediately
- No generic fantasy filler; every character should feel like a recognizable Squabblemon social class

The current production references are in `assets/transparent/` and the wired card set is in `current-playtest/assets/characters/`.
