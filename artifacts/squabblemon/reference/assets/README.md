# Playtest Assets

`characters/` contains optimized transparent WebP copies of the 20 production-style character illustrations currently wired into the prototype. Characters without new production art still fall back to their legacy sprite URL.

The animated Flame Orb, Yellow Liquid Orb, Battle FX sheet, props, and full-resolution transparent masters live in the repository-level `assets/transparent/` library and are referenced directly by the build where used.

See `../../docs/FX_AND_SPRITE_HANDOFF.md` for the mapping and implementation notes.
