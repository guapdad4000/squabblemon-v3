# Season One — the full dialogue, chapter by chapter

This is the shipped screenplay. It is the same content as
`artifacts/squabblemon/scripts/story/rewrites/season-one/READTHROUGH.md`,
which is the file the game compiles from. Kept separately so it can be read
without touching the build.

Battle nodes play `PRE` before the match and `POST` after it.
**The engine plays exactly one section per node visit** — the player never
sees pre and post in the same sitting without playing in between.
